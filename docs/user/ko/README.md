# 사용자 가이드

애플리케이션은 아직 배포되지 않았습니다. 이 가이드는 설치, 관리자 권한 실행, 장치 설정, 프로필 선택, 진단 및 안전한 복구 방법을 다룰 예정입니다.

## 작성 예정 항목

- [호환성](compatibility.md)
- 설치 및 관리자 권한 실행
- 최초 실행 시 장치 식별
- 5K, 6K 및 10K 프로필
- 키 매핑 및 설정
- LED 동작
- Release All 및 복구
- 문제 해결과 진단 자료 생성
- RP2030 + FT232RL 하드웨어 브리지 설정

설정명, 프로필 ID, 버튼명 및 오류 코드는 언어별 문서에서 동일하게 유지합니다.
